# German Credit Risk Simulation: 从过拟合到鲁棒性实验

## 项目综述 (Project Overview)
本项目基于经典的 **German Credit Dataset**，构建了一个端到端的银行信贷违约预测系统。
与常规项目不同，本项目通过对比实验，深入探讨了**数据泄露 (Data Leakage)** 与 **模型鲁棒性 (Robustness)** 之间的关系。

由于原始数据缺乏标签，我基于银行风控逻辑生成了模拟标签，并上传了两个版本的代码来展示模型在不同数据环境下的表现。

## 文件与实验对比 (Files & Experiment)

我上传了两个不同版本的实验代码，以展示“死记硬背”与“真实模拟”的区别：

### 1. `Credit_Risk_Project.py` (数据泄露/过拟合演示)
* **逻辑：** 使用严格的确定性规则（如：无存款+高负债=必违约）生成标签。
* **表现：** 模型准确率达到 **99% - 100%**。
* **问题：** 虽然分数极高，但这演示了典型的 **Data Leakage（数据泄露）**。模型并没有学习风控规律，而是直接“破解”了生成规则。这种模型在现实世界中是不可用的。

### 2. `Credit_Risk_Project_Updated.py` (最终鲁棒性版本)
* **改进：** 在标签生成过程中注入了 **8%-15% 的随机噪音 (Random Noise)**，模拟真实世界中优质客户意外违约的不确定性。
* **表现：** 准确率稳定在 **85%** 左右。
* **结论：** 虽然准确率下降了，但模型学会了在噪音中提取核心特征（Feature Extraction），具备了真正的**泛化能力**，符合工业界风控模型的真实水平。

## 核心业务逻辑 (Business Logic)
为了还原真实的信贷审批，我的风险规则综合考量了以下维度：
1.  **偿债能力：** `Checking/Saving accounts` (账户余额)
2.  **债务负担：** `Credit amount` (贷款金额) 与 `Duration` (期限)
3.  **不确定性：** 引入随机因子模拟现实世界的“黑天鹅”事件。

## 关键洞察 (Insights)
对比两个模型发现：
* 在 `Credit_Risk_Project.py` 中，特征重要性极其集中，模型完全依赖规则涉及的几个变量。
* 在 `Credit_Risk_Project_Updated.py` 中，由于噪点的加入，特征重要性分布更平滑，模型开始关注潜在的次要特征，证明其鲁棒性更强。
